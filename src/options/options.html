Jev Ad Block

配置 API key 后，Jev 会在任意 HTTP(S) 网页上把本地筛出的候选元素发给 TypeSafe 判断；网络拦截在全局与本页均启用时生效，本地规则在无 key 或请求失败时兜底。API key 仅保存在本机。

请求只包含本地筛出的候选：最多 240 字可见文字、元素标签/区域/尺寸、广告标记、外链域名，以及浮层几何与交互信号；不包含页面 URL、标题、完整页面或链接路径与查询参数。候选文字仍可能含个人信息。
